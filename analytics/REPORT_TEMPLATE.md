## 📢 先週のハイライト
（MC風オープニング。投稿数・活動人数を1〜2文で。週間チャレンジ王者・デイリーの主役（平日皆勤や鬼目標突破）・月間ダービー首位を一言ずつ紹介して引き込む）

## 🏆 先週の週間チャレンジ（本戦）
（`weeklyChallenge` を主役に。休止週なら「今週は休止」と告知してこの節を終える）
- **先週の種目**: `exercises` を紹介（バーバリアンは「短いほど良い」と明記）。`overrideLabel` があれば特別イベント週としてラベル名と「4種目・低い3種目を採用」を一言。
- **優勝者**: `champion` を発表。`perfect:true` なら「全種目1位の完全優勝」と最大級に煽る。`leadMargin` で独走か接戦かを描写。
- **順位表**: `standings` を上から。合計点と、`perExercise` で光った種目（`isLeader`）を一言。
- **逆転のカギ**: `perUser` の `gapToNextUp` / `improvable` / `missingExercises` で、2位以下に「あと○点・どの種目を詰めれば上がるか」を煽り実況。

## 🎯 デイリーミッション（毎日の関門）
（`dailyMission`。無い／null なら「デイリーミッションの集計は準備中」と1行だけ書いてこの節を終える。`inProgress:true` の日は結果に含めない）
- **今週の顔ぶれ**: `days` の各日の種目を1行ずつ（例「月 スクワット / 火 懸垂 …」）。`raid` のある日は「レイド（協力戦）」と明記。
- **入場券レース**: `perUser` を `weekdayClearDays` の多い順に。`allWeekdaysCleared:true` の人は「平日皆勤」として称える。`clearStreak` も添える。
- **名場面**: `highlights` から数件。
  - `rareClears` … 上位○%（`topPct`）の鬼目標を突破（最大の見せ場）
  - `nearMisses` … あと□回で届かず（前向きに煽る）
  - `overkills` … 目標の○倍をやり切った
  - `allClearDays` … 動いた全員がクリアした日
- **関門と本戦**: `gate` から、入場券を得た日数（`weekdayClearDays`）と本戦に投稿した日数（`weeklyPostDays`）を本戦の結果と結びつけて一言。
- 目標回数は人ごとに違うので、回数の大小で人を比べないこと。

## 👑 月間ダービー（シーズンレース）
（`monthlyDerby`。`monthOver:false` の間は「暫定」「途中経過」と明記）
- **首位**: `leader` と `leadMargin`。`standings[].weeklyScores` で週ごとの伸びを描写。
- **残りの戦い**: `weeks` の数と確定状況から「あと何週、逆転の余地」を煽る。
- `monthOver:true` のときだけ「{{monthlyDerby.year}}年{{monthlyDerby.month}}月チャンプ確定！」と正式に戴冠。

## 🛠️ 種目ラボ — 作成と評価の交流
（`ratingScene`）
- **種目職人**: `creators` 上位（作成数・平均評価・代表作 `lovedExercise`）。
- **名作 / 殿堂**: `mostLoved` から数件（作者と評価コメント付き）。
- **目利き・盛り上げ役**: `topEvaluators`。
- **評価の縁**: `engagement` から「誰が誰の種目に熱心か」を1〜2組。
- **名言・珍言**: `notableComments` から2〜3個。
- **新メニュー**: `freshExercises` があれば「今週の新作種目」として紹介。
